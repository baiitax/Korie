# AML Regulatory Adapters & Sovereign Filing Protocols

## 1. Multi-Jurisdictional Reporting Adapters
- **Nigeria (NFIU / CBN)**:
  - Suspicious Transaction Reports (STR)
  - Currency Transaction Reports (CTR for cash $> \text{NGN } 5,000,000$)
  - Format: GoAML XML / JSON Compliant Data Package
- **Niger Republic (CENTIF / BCEAO)**:
  - Déclaration de Soupçon (DS)
  - UEMOA Cross-Border Remittance Compliance Filings
  - Format: BCEAO Secure Portal EDI Package
