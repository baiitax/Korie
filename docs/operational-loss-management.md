# Operational Loss Event Management & Root-Cause Remediation

## 1. Operational Loss Event Lifecycle
Operational loss events are tracked from detection through financial recovery and control remediation:

$$\text{DETECTED} \longrightarrow \text{RECORDED} \longrightarrow \text{VALIDATED} \longrightarrow \text{QUANTIFIED} \longrightarrow \text{ROOT\_CAUSE} \longrightarrow \text{RECOVERY} \longrightarrow \text{CLOSED}$$

$$\text{Net Loss} = \text{Gross Operational Loss} - \text{Insurance Recoveries} - \text{Chargeback/Settlement Recoveries}$$

---

## 2. Standardized Basel Loss Event Categories
- `INTERNAL_FRAUD`: Rogue agent collusion, till theft, insider credential misuse.
- `EXTERNAL_FRAUD`: Card skimming, account takeover, SIM swap social engineering.
- `EXECUTION_DELIVERY_PROCESS_MANAGEMENT`: Misrouted settlement batches, unapplied GL adjustments, till counting errors.
- `BUSINESS_DISRUPTION_SYSTEM_FAILURES`: Cloud outage, payment switch downtime, telecommunications loss.
- `CLIENTS_PRODUCTS_BUSINESS_PRACTICES`: Tariff overcharging, consumer dispute mishandling.
