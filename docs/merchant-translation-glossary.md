# KORIEPAY MERCHANT SYSTEM TRANSLATION GLOSSARY
## Trilingual Terminology Matrix: English (`en`), Hausa (`ha`), and French (`fr`)

---

## 1. Commerce & Financial Core Terms

| English (`en`) | Hausa (`ha`) | French (`fr`) | Context / Definition |
|---|---|---|---|
| Available Balance | Kudin da ke Akwai | Solde Disponible | Unencumbered funds ready for payout or auto-sweep |
| Pending Settlement | Kudin da ke Jira | Règlement en Attente | Transactions in clearing window before nightly batch |
| Gross Sales | Jimlar Tallace-tallace | Ventes Brutes | Total customer payments before MDR fee deduction |
| Net Revenue | Kudin Shiga Tsaye | Revenu Net | Settled earnings after platform processing fee |
| Receive Payment | Karbi Kudi | Recevoir un Paiement | Instant in-store collection action (QR/Transfer) |
| Payment Link | Mahadar Biyan Kudi | Lien de Paiement | Web URL for remote omnichannel checkout |
| Commercial Invoice | Rasidin Haraji na Ciniki | Facture Commerciale | Formal B2B tax invoice with line items & VAT |
| Dynamic NUBAN | Lambar Asusun Banki na Zamani | NUBAN Virtuel Dynamique | Transaction-bound virtual bank account |
| Auto-Sweep | Tura Kudi ta atomatik | Virement Automatique | Automatic end-of-day bank clearing |
| Double-Entry Reconciliation | Daidaita Lissafin Kudi na Biyu | Rapprochement Comptable | Verification matching ledger vs bank statement |
| Branch Store | Reshen Shago | Succursale / Magasin | Physical retail location / distribution depot |
| Staff Permissions | Izinin Ma'aikata | Permissions du Personnel | Granular RBAC role security privileges |
| Webhook Endpoint | Tashar Sanarwa ta Webhook | Point de Terminaison Webhook | Server URL receiving real-time event notifications |
| Chargeback Dispute | Rigimar Mayar da Kudi | Litige de Rétrofacturation | Disputed transaction raised by customer's bank |
