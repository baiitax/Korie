# Agent Network KYC & Geolocation Supervision

## Agent Onboarding Standards
1. **Tiered Agent Categorization**: Individual POS Agent, Corporate Super-Agent, Cross-Border Remittance Point.
2. **Physical Shop Inspection & Geolocation**: Verification of GPS coordinates of physical kiosk or retail premises against municipal registry records.
3. **Daily Liquidity & Float Caps**: System-enforced daily wallet funding limits preventing unmonitored cash hoarding.

## Anti-Smurfing Surveillance in Agent Networks
- **Agent Rapid Cycling Detection**: Triggers alert when multiple distinct customer cards/wallets withdraw maximum limits at the same physical agent POS terminal within short time intervals.
- **Immediate Restriction Trigger**: Automatic POS terminal suspension when chargeback/fraud report threshold exceeds 1.0% in any 7-day rolling period.
