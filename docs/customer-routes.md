# KORIEPAY CUSTOMER BANKING PORTAL — ROUTE DIRECTORY

| Route | Functionality | Primary Actions |
|---|---|---|
| `/customer` | Mobile-First Banking Dashboard | Greeting, Multi-Currency Balance Hero, Quick Actions, Recent Activity |
| `/customer/send-money` | 5-Step Transfer & Bilateral Flow | Bank selection, Account Name Inquiry, Fee Calculation, PIN Modal |
| `/customer/receive-money` | Dedicated Bank Details & QR Generator | Virtual Providus NUBAN, Koris IBAN, Dynamic QR, Web Share |
| `/customer/transactions` | Transaction Activity & Search | Search, Multi-rail filters, CSV statement download, Receipt modal |
| `/customer/bills` | Utility & Telecom Payment Desk | Airtime Top-Up, Data Packages, Electricity Prepaid Token Vending, Cable TV |
| `/customer/cards` | Virtual & Physical Card Controls | USD & NGN Visa/Mastercard, Card freeze toggle, Monthly spend limit |
| `/customer/fx` | Bilateral Foreign Exchange Center | 60-second rate lock, Live NGN ⇄ XOF ⇄ USD currency swaps |
| `/customer/beneficiaries` | Saved Recipients Directory | 1-tap Send, Add Beneficiary, Delete, Search |
| `/customer/wallets` | Multi-Currency Vaults | NGN Providus Vault, XOF Koris Vault, USD Treasury Vault |
| `/customer/kyc` | Tier Verification & Limit Upgrades | Tier 1 to Tier 3 roadmap, CAC/NIN document upload simulator |
| `/customer/security` | 2FA, Biometrics & Active Sessions | 2FA switch, Biometrics switch, Remote device revocation |
| `/customer/support` | Resolution Desk & Disputes | Create ticket, One-tap transaction dispute attachment, Live FAQs |
| `/customer/profile` | Customer Profile & Identifiers | BVN, NIN, Verified jurisdiction, Account status |
| `/customer/settings` | Language & Notification Center | English / Hausa / Français selector, SMS & Email receipt toggles |
| `/login` | Secure Customer Login | Phone/Email, Password toggle, Biometric FaceID login |
| `/register` | Tier 1 Account Opening | Country selection 🇳🇬 / 🇳🇪, Personal details, Regulatory compliance |
| `/otp` | SMS / Email 6-Digit Verification | Auto-focusing numeric input, Resend countdown |
| `/forgot-password` | Account Recovery | Registered identifier lookup and reset link dispatch |
