# KORIEPAY DEVELOPER ONBOARDING LIFECYCLE GUIDE

## 1. Step-by-Step Onboarding Funnel

```
Create Developer Account
         │
         ▼
Verify Organization (CAC / RCCM)
         │
         ▼
Access Developer Dashboard
         │
         ▼
Generate Sandbox API Keys (`kp_test_...`)
         │
         ▼
Execute First Test Request in API Explorer
         │
         ▼
Configure Webhook Endpoint & Verify HMAC
         │
         ▼
Complete 6-Point Readiness Checklist
         │
         ▼
Submit Providus / Koris Settlement Bank Details
         │
         ▼
Receive Live Production Credentials (`kp_live_...`)
```

---

## 2. Onboarding SLAs
- Sandbox Key Issuance: Instant (< 5 seconds)
- Automated Checklist Verification: Real-Time (< 1 second)
- Production Compliance Review: Under 4 Business Hours for Tier 1 Verified Entities.
